# malka-claude-mods

A personal collection of [Claude Code](https://claude.com/claude-code) mods, published so anyone can install whichever ones they like. Each mod is an independent plugin: install only the ones you want.

## Install

Add the marketplace once:

```
/plugin marketplace add danielmalka/malka-claude-mods
```

Then install the mods you want, one at a time:

```
/plugin install sentinel@malka-claude-mods
/plugin install resume@malka-claude-mods
/plugin install statusline@malka-claude-mods
/plugin install cleanscreen@malka-claude-mods
/plugin install mode@malka-claude-mods
/plugin install permissions@malka-claude-mods
/plugin install menu@malka-claude-mods
```

## Mods

| Mod | Description | Status |
| --- | --- | --- |
| [sentinel](plugins/sentinel/README.md) | Live band above the prompt with running subagents and background Bash. | available |
| [resume](plugins/resume/README.md) | Offers Resume/Dismiss when the previous session was interrupted mid-turn. | available |
| [statusline](plugins/statusline/README.md) | Status line with model, folder, branch, context bar, 5h/7d limits and cache state. | available |
| [cleanscreen](plugins/cleanscreen/README.md) | Hides tool calls; shows Claude's text and a progress band above the prompt. | available |
| [mode](plugins/mode/README.md) | Switch model and effort from a panel. | available |
| [permissions](plugins/permissions/README.md) | Show the permission mode and pick the one new sessions start in. | available |
| [menu](plugins/menu/README.md) | Optional shared settings menu for whichever of these mods are installed. | available |

# Português

Uma coleção pessoal de mods do [Claude Code](https://claude.com/claude-code), publicada para que qualquer pessoa instale os que quiser. Cada mod é um plugin independente: instale só os que interessam.

## Instalação

Adicione o marketplace uma vez:

```
/plugin marketplace add danielmalka/malka-claude-mods
```

Depois instale os mods que quiser, um de cada vez:

```
/plugin install sentinel@malka-claude-mods
/plugin install resume@malka-claude-mods
/plugin install statusline@malka-claude-mods
/plugin install cleanscreen@malka-claude-mods
/plugin install mode@malka-claude-mods
/plugin install permissions@malka-claude-mods
/plugin install menu@malka-claude-mods
```

## Mods

| Mod | Descrição | Status |
| --- | --- | --- |
| [sentinel](plugins/sentinel/README.md) | Faixa ao vivo acima do prompt com subagentes e comandos Bash em segundo plano. | disponível |
| [resume](plugins/resume/README.md) | Oferece Resume/Dismiss quando a sessão anterior foi interrompida no meio de um turno. | disponível |
| [statusline](plugins/statusline/README.md) | Linha de status com modelo, pasta, branch, barra de contexto, limites de 5h/7d e estado do cache. | disponível |
| [cleanscreen](plugins/cleanscreen/README.md) | Oculta chamadas de ferramenta; mostra o texto do Claude e uma faixa de progresso acima do prompt. | disponível |
| [mode](plugins/mode/README.md) | Escolhe modelo e esforço num painel. | disponível |
| [permissions](plugins/permissions/README.md) | Mostra o modo de permissão e escolhe o modo em que novas sessões começam. | disponível |
| [menu](plugins/menu/README.md) | Menu de configurações compartilhado e opcional, para os mods instalados. | disponível |

Cada mod é instalável sozinho. O `menu` é opcional e lista só os mods que você instalou.
