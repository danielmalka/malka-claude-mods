# cleanscreen

A "Clean screen" mode for Claude Code. While it is on, tool calls and their output are hidden: you see Claude's text, plus a progress band above the prompt (task title, step list, percent bar, elapsed time). Claude feeds the band through an MCP tool, `cleanscreen_progress` (`mcp__cleanscreen__cleanscreen_progress`); `TodoWrite` and the Task tools update it too.

It is **off by default**.

## Install

```
/plugin marketplace add danielmalka/malka-claude-mods
/plugin install cleanscreen@malka-claude-mods
```

## Commands

- `/cleanscreen on` / `/cleanscreen off`
- `/cleanscreen theme <blue|dark|light|green|rainbow|custom>`
- `/cleanscreen color <bar|text|border> <#rrggbb>` sets the `custom` theme's colors (use `/cleanscreen theme custom` to show them)
- `/cleanscreen` with no argument opens the settings pane (On / Off, theme, custom colors)

Your choices are remembered across sessions.

## With or without the menu

Works on its own. With the optional `menu` mod installed, it lists "Clean screen" (`off`, or `on · <theme> band`) and shows the same settings page inside the menu's pane, with a back button.

## Privacy

It only changes what is displayed. Nothing is sent anywhere, no files are read or written, and the conversation Claude sees is unchanged, except that while it is on, each typed prompt carries a short instruction telling Claude to report progress through the tool. While off, no instruction is added and the tool is not offered to the model. (A session that turned it on and then off keeps the tool registered until restart; it then only answers that the mode is off.)

The band and the instruction start for prompts you type, in the terminal or through Remote Control. SDK prompts get hidden tool rows but no band. Tool calls that errored, were refused or were interrupted are never hidden.

## Uninstall

```
/cleanscreen off
/plugin uninstall cleanscreen@malka-claude-mods
```

## Development

Type declarations in `.claude-plugin/types/` are generated by Claude Code when the mod loads (not committed); the mod's state contract is `types/index.d.ts`, and `types/menu.d.ts` vendors the `menu` mod's contract (apiVersion 1). Then `claude plugin test plugins/cleanscreen`.

# Português

Um modo "Clean screen" para o Claude Code. Ligado, as chamadas de ferramenta e suas saídas ficam ocultas: você vê só o texto do Claude e uma faixa de progresso acima do prompt (título, lista de passos, barra de porcentagem, tempo decorrido). O Claude a alimenta pela ferramenta MCP `cleanscreen_progress` (`mcp__cleanscreen__cleanscreen_progress`); `TodoWrite` e as ferramentas de Task também a atualizam.

Vem **desligado**.

**Instalar:** `/plugin marketplace add danielmalka/malka-claude-mods` e `/plugin install cleanscreen@malka-claude-mods`.

**Comandos:** `/cleanscreen on|off`; `/cleanscreen theme <blue|dark|light|green|rainbow|custom>`; `/cleanscreen color <bar|text|border> <#rrggbb>` (cores do tema `custom`); `/cleanscreen` sem argumento abre o painel de configuração. As escolhas ficam salvas entre sessões.

**Com ou sem menu:** funciona sozinho. Com o mod opcional `menu`, aparece na lista ("Clean screen", `off` ou `on · <tema> band`) e mostra a mesma página dentro do painel do menu.

**Privacidade:** só altera o que é exibido. Nada é enviado para fora nem gravado em arquivos. Ligado, cada prompt digitado leva uma instrução curta pedindo ao Claude que reporte o progresso pela ferramenta; desligado, nenhuma instrução é adicionada e a ferramenta não é oferecida ao modelo (numa sessão em que foi ligado e depois desligado, a ferramenta segue registrada até reiniciar e apenas responde que o modo está desligado).

A faixa e a instrução começam para prompts que você digita, no terminal ou pelo Remote Control. Prompts do SDK têm as linhas ocultas, mas sem faixa. Chamadas com erro, recusadas ou interrompidas nunca são ocultadas.

**Desinstalar:** `/cleanscreen off` e depois `/plugin uninstall cleanscreen@malka-claude-mods`.
