# mode

Pick the model and the reasoning effort from one small pane, or from `/mode`. It does **nothing until you pick something**: while no effort is chosen, every request goes out untouched.

- `/mode` opens the pane (model: Fable, Opus, Sonnet, Haiku or Claude Code's default; effort: low, medium, high, xhigh, max or default).
- `/mode model <alias>` switches the model (`fable`, `opus`, `sonnet`, `haiku`, `default`) through Claude Code's own `/model`.
- `/mode effort <level>` sets the effort of every request of the main conversation (subagents are left alone). The level is remembered across sessions; levels a model does not support are handled by Claude Code. It never writes your `/config`. If you later change the effort yourself with `/effort`, that newer choice wins and the mod drops its override. `/mode effort default` removes the override.
- It publishes `mode.manual` (true once you picked a model or an effort in the current session) for other mods to read.

Works on its own, or together with the optional `menu` mod: then the menu lists "Mode" (for example `Opus 5.5 · effort high`) and shows this page in its pane. It never writes `settings.json`.

## Install

```
/plugin marketplace add danielmalka/malka-claude-mods
/plugin install mode@malka-claude-mods
```

## Uninstall

```
/mode effort default
/plugin uninstall mode@malka-claude-mods
```

`/mode effort default` clears the remembered level. The model stays whatever you last chose with `/model`.

## Development

Type declarations in `.claude-plugin/types/` are generated by Claude Code when the mod loads (not committed); the mod's own state contract is `types/index.d.ts`, and `types/menu.d.ts` vendors the `menu` mod's contract (apiVersion 1). Then `claude plugin test plugins/mode`.

# Português

Escolha o modelo e o esforço de raciocínio num painel pequeno ou com `/mode`. **Não faz nada até você escolher algo**: sem esforço escolhido, as requisições seguem intactas.

- `/mode` abre o painel (modelo: Fable, Opus, Sonnet, Haiku ou o padrão do Claude Code; esforço: low, medium, high, xhigh, max ou default).
- `/mode model <alias>` troca o modelo (`fable`, `opus`, `sonnet`, `haiku`, `default`) pelo `/model` do próprio Claude Code.
- `/mode effort <nível>` define o esforço de cada requisição da conversa principal (subagentes ficam de fora), lembrado entre sessões; níveis que o modelo não suporta são tratados pelo Claude Code. Nunca escreve no seu `/config`; se você mudar o esforço com `/effort`, a sua escolha vence e o override é descartado. `/mode effort default` remove o override.
- Publica `mode.manual` (verdadeiro quando você escolheu modelo ou esforço na sessão atual) para outros mods lerem.

Funciona sozinho ou com o mod opcional `menu` (que lista "Mode" e mostra a página no seu painel). Nunca escreve no `settings.json`.

**Instalar:** `/plugin marketplace add danielmalka/malka-claude-mods` e depois `/plugin install mode@malka-claude-mods`.
**Desinstalar:** rode `/mode effort default` e então `/plugin uninstall mode@malka-claude-mods`.
