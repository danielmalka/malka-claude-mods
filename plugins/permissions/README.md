# permissions

Pick the permission mode that **new sessions start in** (`permissions.defaultMode` in your user `settings.json`) from one small pane, or from `/permmode`. It **does nothing until you pick something**: installing it writes no file.

- `/permmode` opens the pane: the six modes (ask, plan, accept edits, auto, don't ask, bypass permissions) with the current default marked.
- `/permmode <mode>` sets the default directly (`default`, `plan`, `acceptEdits`, `auto`, `dontAsk`, `bypassPermissions`); any other argument prints the usage. `bypassPermissions` is the exception: it can only be picked in the pane, so a model calling the command cannot turn every check off.
- The pane also has a "Running in" line. A mod cannot read the running session's mode, so it shows `unknown`; switch the running mode with shift+tab. The mod never changes the running session's mode.
- `bypassPermissions` skips every permission check. While it is the default, the pane shows the warning "Bypass skips every permission check in every new session."

What it writes: only `permissions.defaultMode`; every other key of `settings.json` is kept. The first change saves the original file as `settings.json.permissions.bak`, and every default it replaces is appended to `settings.json.permissions.prev.bak`. An invalid `settings.json` is never overwritten (a toast says so). The file is `$CLAUDE_CONFIG_DIR/settings.json`, else `~/.claude/settings.json`.

`/permissions` is a Claude Code built-in, hence the name `/permmode`.

Works on its own, or together with the optional `menu` mod: then the menu lists "Permissions" and shows this page in its pane.

## Install

```
/plugin marketplace add danielmalka/malka-claude-mods
/plugin install permissions@malka-claude-mods
```

## Uninstall

```
/plugin uninstall permissions@malka-claude-mods
```

The mode you picked stays in `settings.json`; to undo it, pick another with `/permmode default` (or edit `permissions.defaultMode` by hand). `settings.json.permissions.bak` is a last-resort copy of the file as it was before the first pick; restoring it drops every later change.

## Development

Type declarations in `.claude-plugin/types/` are generated by Claude Code when the mod loads (not committed); the mod's own state contract is `types/index.d.ts`, and `types/menu.d.ts` vendors the `menu` mod's contract (apiVersion 1). Then `claude plugin test plugins/permissions`.

# Português

Escolha o modo de permissão em que **novas sessões começam** (`permissions.defaultMode` no `settings.json` do usuário) num painel pequeno ou com `/permmode`. **Não faz nada até você escolher algo**: instalar não grava arquivo nenhum.

- `/permmode` abre o painel: os seis modos (ask, plan, accept edits, auto, don't ask, bypass permissions), com o padrão atual marcado.
- `/permmode <modo>` define o padrão direto (`default`, `plan`, `acceptEdits`, `auto`, `dontAsk`, `bypassPermissions`); qualquer outro argumento mostra o uso. `bypassPermissions` é a exceção: só pode ser escolhido no painel, para que um modelo chamando o comando não desligue todas as verificações.
- O painel tem também a linha "Running in". Um mod não consegue ler o modo da sessão em andamento, então mostra `unknown`; troque o modo atual com shift+tab. O mod nunca muda o modo da sessão em andamento.
- `bypassPermissions` pula toda verificação de permissão. Enquanto ele for o padrão, o painel mostra o aviso "Bypass skips every permission check in every new session." (o texto é exibido em inglês, como os demais rótulos do painel).

O que grava: só `permissions.defaultMode`; as demais chaves do `settings.json` ficam intactas. A primeira alteração guarda o arquivo original em `settings.json.permissions.bak`, e cada padrão substituído é acrescentado a `settings.json.permissions.prev.bak`. Um `settings.json` inválido nunca é sobrescrito (um aviso informa). O arquivo é `$CLAUDE_CONFIG_DIR/settings.json`, senão `~/.claude/settings.json`.

`/permissions` é um comando nativo do Claude Code, daí o nome `/permmode`.

Funciona sozinho ou com o mod opcional `menu` (que lista "Permissions" e mostra a página no seu painel).

**Instalar:** `/plugin marketplace add danielmalka/malka-claude-mods` e depois `/plugin install permissions@malka-claude-mods`.
**Desinstalar:** `/plugin uninstall permissions@malka-claude-mods`. O modo escolhido continua no `settings.json`; para desfazer, escolha outro com `/permmode default` (ou edite `permissions.defaultMode` à mão). `settings.json.permissions.bak` é uma cópia de último recurso do arquivo como estava antes da primeira escolha; restaurá-la descarta todas as mudanças posteriores.
