# sentinel

A live band above the prompt that shows running subagents and background Bash commands. It costs zero tokens: it only observes events and draws a line.

- Running items with elapsed time, e.g. `⏳ 2 running · builder 1m (active 5s ago) · npm test 3m`
- Stall warning toast when a subagent shows no activity for 5 minutes
- Completion toast when everything has finished (`sentinel: all done (N tasks, 6m)`)
- Finished items linger in the band for one minute

## Install

```
/plugin marketplace add danielmalka/malka-claude-mods
/plugin install sentinel@malka-claude-mods
```

## Uninstall

```
/plugin uninstall sentinel@malka-claude-mods
```

## Development

Type declarations in `.claude-plugin/types/` are generated by Claude Code when the mod loads (not committed). Then `claude plugin test plugins/sentinel` and `tsc -p plugins/sentinel`.

# Português

Uma faixa ao vivo acima do prompt que mostra subagentes e comandos Bash em segundo plano em execução. Custo zero de tokens: só observa eventos e desenha uma linha.

- Itens em execução com tempo decorrido
- Aviso (toast) quando um subagente fica 5 minutos sem atividade
- Toast ao terminar tudo
- Itens concluídos permanecem na faixa por um minuto

**Instalar:** `/plugin marketplace add danielmalka/malka-claude-mods` e depois `/plugin install sentinel@malka-claude-mods`.
**Desinstalar:** `/plugin uninstall sentinel@malka-claude-mods`.
