# resume

Detects that the previous session in the same directory was interrupted in the middle of a turn (crash, closed terminal, machine restart) and shows a band above the prompt with two buttons:

- **Resume** sends a prompt telling Claude the session was interrupted, with your last request, branch and changed files, and asks it to check the real state (git, project notes or handoff files, if any) before continuing.
- **Dismiss** hides the band.

It keeps a small heartbeat (every 30 s) so another live session in the same directory is not mistaken for a crash, and it does nothing in non-interactive runs (`claude -p`). The checkpoint is stored locally by Claude Code.

## Install

```
/plugin marketplace add danielmalka/malka-claude-mods
/plugin install resume@malka-claude-mods
```

## Uninstall

```
/plugin uninstall resume@malka-claude-mods
```

## Development

Type declarations in `.claude-plugin/types/` are generated by Claude Code when the mod loads (not committed); the mod's own state contract is `types/index.d.ts`. Then `claude plugin test plugins/resume` and `tsc -p plugins/resume`.

# Português

Detecta que a sessão anterior no mesmo diretório foi interrompida no meio de um turno e mostra uma faixa acima do prompt com dois botões: **Resume** (envia um prompt com o último pedido, branch e arquivos alterados, pedindo para conferir o estado real antes de continuar) e **Dismiss** (esconde a faixa). Usa um batimento de 30 s para não confundir outra sessão viva com uma queda e não faz nada em execuções não interativas (`claude -p`).

**Instalar:** `/plugin marketplace add danielmalka/malka-claude-mods` e depois `/plugin install resume@malka-claude-mods`.
**Desinstalar:** `/plugin uninstall resume@malka-claude-mods`.
